# Составление Architecture Decisions Records (ADR) для MVP оформления депозитоп онлайн

ADR изложены в файле [ADR.rst](./ADR.rst). Формат ReStructuredText был выбран
для сохранения редактируемости таблиц (в RST ячейки могут быть многострочными,
но при этом не терять ретактируемости).

Хотелось бы, чтобы задания учили использовать адекватные инструменты для решения
задач. Сложные таблицы в Markdown — ужас.
